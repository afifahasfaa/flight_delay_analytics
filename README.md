## ✈️ Flight Delay Analytics

## ⚙️ Tools Used
- Microsoft Excel
- Tableau

## 📝 Project Overview
Flight Delay Analytics is an interactive analytics dashboard designed to evaluate airline operational reliability, flight disruption patterns, and geographical delay distributions. The aviation industry faces ongoing challenges in minimizing flight delays, managing carrier performance, and improving passenger experience. This dashboard provides executive-level KPIs and detailed visualizations to help stakeholders identify root causes of delay, assess monthly disruption trends, and optimize operational efficiency across major US airports and carriers.

## 📊 Dataset Used
- Raw data: raw data from Kaggle
- Clean data: https://github.com/afifahasfaa/flight_delay_analytics/blob/main/datafix.xlsx

## ❔ Question 
1.	Which carrier experienced the highest total arrival delay across all airports?  
2.	What is the primary contributing factor to overall delay duration (e.g., Late Aircraft, Carrier, Weather, NAS, or Security)?   
3.	Which specific month recorded the highest spike in total arrival delays?   
4.	Which geographic region/state shows the highest concentration of delayed flights?   
5.	What is the overall average delay rate (%) across all flights during the analyzed period?
